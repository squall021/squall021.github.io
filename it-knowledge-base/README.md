# IT 問題處理知識庫 V2

## 功能
- 問題紀錄新增、編輯、刪除
- 全文搜尋、分類、日期、收藏篩選
- 分類圖示自訂
- 卡片 / 列表顯示切換
- 圖片附件（本機 IndexedDB）
- JSON 匯入 / 匯出備份
- Google 試算表文字資料同步

## Google 試算表同步設定
1. 建立一份新的 Google 試算表。
2. 開啟「擴充功能 → Apps Script」。
3. 將 `apps-script/Code.gs` 全部貼入並儲存。
4. 執行 `setup()` 一次，授權後在執行記錄中取得 `SYNC_KEY`。
5. Apps Script 右上角選「部署 → 新增部署 → 網頁應用程式」。
6. 執行身分選「我」，存取權限選「任何人」。
7. 複製 `/exec` 結尾的 Web App 網址。
8. 回到知識庫，開啟「雲端同步」，輸入 Web App 網址與 `SYNC_KEY`。
9. 第一次先按「上傳全部資料」，之後可開啟自動同步。

> 圖片附件目前只保存在各瀏覽器本機，不會寫入 Google 試算表。跨電腦同步的是文字紀錄、分類、標籤、收藏等欄位。

## 安全性
Web App 必須允許「任何人」存取，前端才能從 GitHub Pages 呼叫。後端會再驗證 `SYNC_KEY`。請勿把自己的同步金鑰寫入 GitHub 原始碼或分享給其他人。
